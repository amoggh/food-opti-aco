# Configuration Module

This module will contain centralized configuration management for all backend services and algorithms.

## Future Responsibilities
- **ACO Parameters**: Alpha, beta, evaporation rate (rho), initial pheromone (tau_0), ant colony size, and max iterations.
- **Simulation Parameters**: Virtual clock speed, tick duration, random seed, rider speed defaults, and order arrival rates.
- **Dataset Configuration**: Paths and metadata for raw and processed benchmark datasets.
- **Optimization Weights**: Multi-objective fitness function coefficients (delay penalties, distance vs. time trade-offs).

*Implementation will be added during early phases.*
