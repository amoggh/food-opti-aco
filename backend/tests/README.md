# Backend Tests

This directory will contain the automated test suites for the backend components.

## Future Structure
- **Unit Tests**: Verifying individual algorithms (pheromone decay, heuristic calculations, route graph shortest paths).
- **Integration Tests**: Verifying pipeline flow across data loading, ACO solver execution, and simulation state transitions.
- **API Tests**: Validating FastAPI route schemas, response payloads, and WebSocket events.

*Tests will be developed alongside each module starting from Phase 1.*
