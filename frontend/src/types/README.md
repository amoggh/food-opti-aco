# Types

This directory will contain TypeScript interfaces and type declarations.

## Future Responsibilities
- **Domain Models**: Types for Orders, Restaurants, Delivery Riders, Road Nodes, and Road Edges.
- **Simulation Types**: Event types, status enums, and simulation clock configurations.
- **API Payloads**: Request and response interfaces matching FastAPI Pydantic models.
- **ACO Configuration Types**: Parameter typing for algorithm hyper-parameters and fitness weights.
